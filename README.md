# Unit Converter

A simple web-based unit converter application built with Node.js, Express, and EJS.
Sample solution for the <a href="https://roadmap.sh/projects/unit-converter" target="_blank">unit-converter</a> challenge from <a href="https://roadmap.sh" target="_blank">roadmap.sh</a>.

## Features

- Convert between various units across categories such as Length, Weight, Temperature, Area, Volume, Time, and Speed.
- Responsive and user-friendly interface.
- Real-time conversion using an Express backend.

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/biswajit-halder/unit-converter.git
   ```
2. Navigate to the project directory:
   ```sh
   cd unit-converter
   ```
3. Install Node.js if not already installed.

## Usage

Run the application using the following command:
    ```sh
    npm start
    ```
